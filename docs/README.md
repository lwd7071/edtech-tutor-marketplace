# Bản đồ tài liệu

Đọc theo nhu cầu, không cần mở toàn bộ thư mục docs:

| Câu hỏi | Tài liệu |
|---|---|
| Dự án là gì, thuật ngữ và invariant nào quan trọng? | [`CONTEXT.md`](../CONTEXT.md) |
| Hiện tại đã làm đến đâu, test nào đã chạy? | [`STATUS.md`](STATUS.md) |
| Những đợt gần đây đã thay đổi hành vi gì? | [`CHANGELOG.md`](CHANGELOG.md) |
| API/DTO/error code/DB contract là gì? | `architecture/API_CONTRACT.md`, `architecture/ERROR_CODES.md`, `architecture/ERD.md` |
| Module và dependency đi qua seam nào? | `architecture/BACKEND_ARCHITECTURE.md`, `architecture/FRONTEND_ARCHITECTURE.md` |
| Cài môi trường và quy ước code ra sao? | `guidelines/SETUP.md`, `guidelines/CODING_CONVENTION.md` |
| Vì sao có một quyết định kiến trúc? | `adr/` |
| Cần xem lịch sử cũ? | `archive/2026-initial-build/` |

[`SPEC.md`](SPEC.md) là đặc tả sản phẩm hiện hành. Các file trong archive chỉ dùng để tra cứu lịch sử, không được dùng để kết luận trạng thái hiện tại.
